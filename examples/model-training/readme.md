# Тонкая настройка (Fine-tuning) LLM на Amazon SageMaker

Репозиторий содержит пошаговое руководство по тонкой настройке (fine-tuning) предобученной большой языковой модели (LLM) класса **Dolly v2 3B** с использованием методов эффективной адаптации параметров (**PEFT / LoRA**) и последующим развертыванием инференса на облачной инфраструктуре **Amazon SageMaker**.

## 📌 Обзор архитектуры решения

Тонкая настройка (Transfer Learning) позволяет взять базовые знания, накопленные моделью на терабайтах текстов, и адаптировать её под узкую предметную область (в данном примере — базу знаний Amazon SageMaker FAQs). Это экономит вычислительные ресурсы по сравнению с обучением с нуля.

### Ключевые оптимизации:

- **Quantization (8-bit):** Сжатие весов модели в INT8 уменьшает потребление видеопамяти без критической потери качества генерации.
- **LoRA (Low-Rank Adaptation):** Замораживает базовые параметры сети и обучает только внедренные низкоранговые матрицы декомпозиции.
